# Brand images

| File | Size | Use |
|---|---|---|
| `queueup-profile.png` | 1080 × 1080 | Profile picture (Facebook, Instagram, LinkedIn, X). Content sits inside the circle crop. |
| `queueup-cover.png` | 1640 × 624 | Facebook page cover. Key content stays in the centre ~1100 px so mobile side-crops keep it. |

Both are rendered from the HTML in `source/` using the app's own palette (ink `#17160F`, paper `#F6F4EE`, marigold `#F2BC1F`) and IBM Plex. To change copy or colours, edit the HTML and screenshot it at the sizes above in Chromium.
